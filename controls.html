Legacy Machine Control System Retrofit

Implemented

Project overview

Following failure of an obsolete machine controller, I designed a sheet-metal pneumatic control panel and a 3D-printed electrical control enclosure and door for a manual-control retrofit. The panel accommodates gauges, regulators and manual levers. Both assemblies were installed and are functional.
