Miniature 3D-Printed Inline-Four Engine

Academic project

Project overview

For a sophomore CAD project, I modeled a miniature inline-four engine using real engine components as references. The open-block model was 3D-printed with moving pistons, a designed cam and firing order, and a DC motor-driven crankshaft that powered a turbine. Original project photographs are unavailable.
